# 计算实验与统计 · 从数字到可辩护的结论

> 实验部分回答三个问题：**比谁好、好多少、这个「好」是不是噪声**。
> 口径必须在跑之前写定；跑完再挑指标 = 事后编故事。
> 配套工具：`scripts/expstats.py`（gap 表 / 性能剖面）、`scripts/paired_stats.py`（配对符号检验，自动拦口径混用）。

---

## 1. 指标：先定义，再计算

| 指标 | 定义 | 用在哪 |
|---|---|---|
| 目标值 $z$ | 可行解的目标函数值 | 所有主表 |
| gap to BKS | $(z-z_{\text{BKS}})/|z_{\text{BKS}}|\times100$ | 与文献比 |
| gap to LB | $(z-z_{\text{LB}})/|z_{\text{LB}}|\times100$ | 无 BKS 时的上界估计 |
| integrality gap | $(z_{IP}-z_{LP})/|z_{IP}|\times100$ | 评价 formulation，不是算法 |
| 命中最优数 | gap ≤ 1e-6 的算例数 | 汇总表必报 |
| time-to-target | 首次达到目标 gap 的时间 | anytime 算法 |
| primal integral | $\int_0^T (z(t)-z^*)\,dt$ 归一化 | 比较收敛过程 |
| 可行性率 | 可行解数 / 总运行数 | 大规模 / 难算例必报 |

**绝对目标值不可跨文献比较**；能比的是 gap，且要说明参考值类型（OPT / BKS / LB）。

## 2. 实验设计（跑之前写死）

| 项 | 要求 |
|---|---|
| 对照臂 | 至少 baseline + 本方法；消融各臂独立命名，绝不覆盖基线结果 |
| 配对键 | 同算例（+ 同种子）配对；不允许「平均值对平均值」 |
| 样本规模 | 算例数 × 种子数 = 预期配对数 n；写入 `--expect-n` |
| 重复次数 | 确定性算法 1 次；随机算法 ≥5 次，报分布而非单次最好 |
| 时间上限 | 所有臂相同；写清硬件与线程 |
| 主表 / 附表 | 主表放主结论，附表放消融与敏感性 |
| 预注册判据 | 什么算「有效」事先定（如 gap 降低 ≥1% 且 p<0.05） |

口径一旦确认，**中途不许改**；要改就回退到 Stage 6 重跑。

---

## 3. 什么叫「配对」

同一 `(instance, seed)`、同一份算例、同一随机流，**只改一个旋钮**：

$$
\Delta = \frac{A-B}{B}\times100\%\qquad(\text{负} = A \text{ 更便宜})
$$

- 配对消除「各种子取最优再比」的极值偏差。
- 两臂的种子/算例集合不同 → 配对不成立，先对齐键。
- 内连接静默丢行 = 事故；A 独有 / B 独有行数必须报出来（`paired_stats.py` 会直接拦）。

**六个数必报**：n（去并列后）、均值、中位、更好/更差/**并列**、双侧符号检验 p、样本口径。并列单列，不能算半票。

## 4. 统计检验

| 场景 | 方法 | 备注 |
|---|---|---|
| 两方法配对、样本 ≥10 | 符号检验 / Wilcoxon signed-rank | 符号检验只看方向，稳健；Wilcoxon 用幅度 |
| 多方法 | Friedman + Nemenyi（或 Holm 校正） | 两两比较必须校正 |
| 比例（可行率） | 卡方 / Fisher 精确 | 小样本用 Fisher |
| 效应量 | Cliff's delta / Cohen's d | 只报 p 不报效应量，容易被质疑「显著但无意义」 |

报告模板：

```
n=20（去并列 2，实际 n=18）；本方法更好 15 例、更差 3 例；
中位 gap 1.8% vs 4.2%；双侧符号检验 p=0.007；Cliff's delta=0.72（大）。
```

`p > 0.05` 写「不显著 / 分不出高低」，不写「有趋势」「边际显著」。

## 5. 性能剖面与图

**性能剖面（Dolan–Moré, 2002）**：每个算例以最好方法的指标为基准，画 $\tau$ 的累积分布。适合展示「整体谁更稳」，不能替代 gap 表。

**箱线图**：按规模分档画 gap 分布，比均值更能暴露尾部。

**临界差异图（CD）**：多方法 Friedman 检验后的秩次可视化。

图必须与表同源（同一次运行、同一 CSV）；图内语言统一，图例不压数据。

## 6. 工具

```bash
# gap 表（分组汇总 + 超时单列 + 「优于参考值」告警）
python expstats.py gap results.csv --ref-csv refs.csv --group solver

# 算例 × 方法 透视表（可显示时间）
python expstats.py table results.csv --ref-csv refs.csv --show-time

# 性能剖面（time 或 gap），导出 CSV 画阶梯图
python expstats.py profile results.csv --ref-csv refs.csv --metric time --out profile.csv

# 配对符号检验（两臂逐配对，口径混用会 exit 2）
python paired_stats.py exp.csv baseline.csv --keys instance,seed --value objective
```

`expstats.py` 会显式报出「结果优于参考值」的行——通常意味着参考值过期、模型漏约束，或解根本不可行。

## 7. 表格规范

```
| 算例 | n | BKS/LB | 基线 obj (gap%) | 本方法 obj (gap%) | 基线 t(s) | 本方法 t(s) |
```

- 加粗每行最优；超时用 `—`，表注写「TL=300s」。
- 汇总行写均值 / 中位数、命中最优数、超时数。
- 小数位统一（gap 两位、时间一位），不要一篇里三种精度。

## 8. 常见陷阱

| 陷阱 | 为什么错 | 正确做法 |
|---|---|---|
| 平均比值 vs 比值平均 | 两者含义不同，易夸大 | 明确写是哪种，优先报告中位 gap |
| 超时当 0 gap | 虚假提升 | 单列未完成，或用时间-质量曲线 |
| 只在测试集上调参 | 数据泄漏 | 调参集 / 测试集分离 |
| 多次运行取最好 | 高估稳定性 | 报均值 / 中位与分布，或固定预算 |
| 显著性检验不配对 | 方差被算例难度放大 | 同算例配对 |
| 只报显著的结果 | 选择性报告 | 负结果、不显著照写 |
| 用不同时限比 | 不公平 | 同时限，或做 anytime 曲线 |
| 把 integrality gap 当算法 gap | 概念混淆 | 分开定义、分表报告 |
| 子集结论写成全量结论 | 样本口径不同 | 子集只做边界复核，单独成段 |
