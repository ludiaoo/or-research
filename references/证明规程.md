# 证明规程 · 正确性、近似比、复杂度与归约

> 这个文件补的是「只要求写清适用条件，却不说怎么得到」的空缺。
> 七套模板，每套给结构、完整范例、常见错误。
>
> **先分清四类证明**——它们的写法完全不同，混用是最常见的硬伤。

---

## 0. 四类证明，别混

| 类型 | 要回答 | 产出 | 典型措辞 | 在哪一节 |
|---|---|---|---|---|
| **A. 解最优** | 这一次求得的解是不是最优 | 下界 = 目标值 + 求解器证书 | 「该算例上最优」 | `松弛与下界.md`（实证，不是理论证明） |
| **B. 模型正确** | 模型与业务问题是否等价 | 四层检验 | 「模型对」 | `建模规范.md` §6 |
| **C. 算法保证** | 算法是否总返回最优/在 ρ 倍内 | 正确性证明 + 近似比 | 「算法 1 是 2-近似的」 | 本文 §1–§6 |
| **D. 问题难度** | 问题本身有多难 | 归约 / 复杂度 | 「该问题是 NP-hard 的」 | 本文 §4 |

**最常见的错误**：用 A 的证据去支撑 C 的结论。
「20 个算例都达到最优」是经验观察，不是「算法最优性证明」。这一句写错，整段理论贡献归零。

## 1. 交换论证（exchange argument）

**用于**：证明某个贪心/局部规则能得到最优解。绝大多数排序与调度结论都靠它。

**模板**：

1. 取任一最优解 $O$，假设它不满足你的规则。
2. 找出 $O$ 中「违反规则」的最小结构（通常是相邻的一对或一段）。
3. 定义交换操作，得到 $O'$。
4. 证 $O'$ **仍然可行**（这是最容易漏的一步）。
5. 证 $O'$ 的目标**不差于** $O$。
6. 由「相邻交换可消除所有违反」归纳，得到与 $O$ 规则一致的解，且不劣。
7. 故存在一个满足规则的最优解；规则唯一确定时即为最优解。

**范例**（$1\,\|\, \sum C_j$ 的 SPT 规则）

> 设最优序中存在相邻两个作业 $j,k$，$j$ 紧前于 $k$，且 $p_j>p_k$。
> 设两者之前所有作业的总加工时间为 $S$。
> 交换前：$C_j=S+p_j$，$C_k=S+p_j+p_k$，两者贡献之和 $=2S+2p_j+p_k$。
> 交换后：$C_k'=S+p_k$，$C_j'=S+p_k+p_j$，两者贡献之和 $=2S+2p_k+p_j$。
> 差值 $=(2S+2p_j+p_k)-(2S+2p_k+p_j)=p_j-p_k>0$，交换后总完成时间严格下降，与 $O$ 最优矛盾。
> 故最优序中不存在这样的相邻逆序，即作业按加工时间非降排列（SPT）。
> ∎

**常见错误**：

| 错误 | 后果 |
|---|---|
| 只证目标不变差，没证可行性 | 交换后可能违约（如时间窗、容量） |
| 交换的是「不相邻」元素却没处理中间项 | 中间作业的完成时间也变了，算漏 |
| 从「不存在相邻逆序」直接跳到「全局最优」 | 需要说明该规则唯一确定一个序 |
| 只在例子上验证交换有效 | 那是实验，不是证明 |

## 2. 归纳与不变量

**用于**：递归/迭代算法的正确性（贪心的逐步选择、DP 的最优子结构、在线算法的竞争比）。

**模板（归纳）**：

1. 明确归纳变量（步数 $t$、规模 $n$、前缀长度 $i$）。
2. **基例**：$t=0$ 或 $n=1$ 时命题成立（不要跳过空集情形）。
3. **归纳假设**：假设 $t-1$（或 $n-1$）时成立。
4. **归纳步**：证第 $t$ 步后仍成立。这里要指出「第 $t$ 步做了什么、为什么不会破坏前面的性质」。
5. 结论：对所有 $t$ 成立。

**模板（不变量）**：找出循环每次迭代前后都成立的性质 $P$，证 (a) 初始化时 $P$ 成立；(b) 若 $P$ 在迭代前成立，迭代后仍成立；(c) 循环终止时 $P$ 蕴含目标结论。

**范例**（区间调度：按结束时间最早贪心最优）

> 命题：按结束时间升序选不重叠区间的贪心算法返回最大基数解。
> 归纳于贪心选择的个数 $t$。设贪心前 $t$ 个选择为 $g_1,\dots,g_t$，存在最优解 $O$ 的前 $t$ 个为 $o_1,\dots,o_t$ 且 $f(g_i)\le f(o_i)$（$f$ 为结束时间）。
> 基例 $t=1$：贪心选全局最早结束的 $g_1$，对任意最优解首元素 $o_1$ 有 $f(g_1)\le f(o_1)$。
> 归纳步：设 $t-1$ 时成立。把 $O$ 中的 $o_t$ 替换为 $g_t$：因 $f(g_{t-1})\le f(o_{t-1})$ 且 $g_t$ 是 $g_{t-1}$ 之后最早结束的可选区间，$g_t$ 与 $o_{t-1}$ 不重叠；又 $f(g_t)\le f(o_t)$，故替换后不与后续区间冲突，$O$ 仍可行且基数不变。
> 归纳完成，贪心解基数等于最优。∎

**常见错误**：基例只做 $n=1$ 不做 $n=0$；归纳步偷偷用了比假设更强的结论；不变量写得太强（实际不成立）或太弱（推不出结论）。

## 3. 对偶论证

**用于**：给下界（证最优）、给近似比（对偶拟合 / 原始-对偶）、证 LP 松弛的紧性。

### 3.1 弱对偶给下界

原问题（最小化）与其对偶：

$$
\min\ c^\top x \ \text{ s.t. } Ax\ge b,\ x\ge0
\qquad\Longleftrightarrow\qquad
\max\ b^\top y \ \text{ s.t. } A^\top y\le c,\ y\ge0
$$

**任意对偶可行 $y$ 都给出下界**：$b^\top y\le c^\top x$（对任意原可行 $x$）。所以只要构造出一个对偶可行解，就有了合法下界，不需要求解。

**范例**（集合覆盖的下界）

> 原问题：$\min\sum_S c_S x_S$ s.t. $\sum_{S\ni e}x_S\ge1\ \forall e$。
> 对偶：$\max\sum_e y_e$ s.t. $\sum_{e\in S}y_e\le c_S\ \forall S$。
> 取 $y_e=\min_{S\ni e} c_S/|S|$。对任意 $S$：$\sum_{e\in S}y_e\le\sum_{e\in S}c_S/|S|=c_S$，故 $y$ 对偶可行。
> 因此 $\sum_e\min_{S\ni e}c_S/|S|\ \le\ z_{LP}\ \le\ z_{IP}$，是一个可 O(mn) 算出的合法下界。

### 3.2 对偶拟合（dual fitting）给近似比

三步：给对偶可行解 → 证对偶目标 $\ge \text{ALG}/\rho$ → 由弱对偶得 $\text{OPT}\ge\text{ALG}/\rho$，即 $\text{ALG}\le\rho\,\text{OPT}$。

若对偶解不严格可行（违反约束），则需按最大违反度 $\alpha$ 缩放：$y/\alpha$ 可行，得 $\rho=\alpha$。

### 3.3 互补松弛判最优

$L\le z\le U$ 且 $L=U$ 时最优。**注意**：这是「证某个解最优」（类型 A），不是「证算法保证」（类型 C）。

**常见错误**：把对偶最优值当作整数最优值（中间还差 integrality gap）；构造的 $y$ 没检查全部约束；符号方向搞反（最大化问题配错对偶）。

## 4. 归约构造（证 NP-hard）

**用于**：说明问题难度，为「为什么用启发式」提供依据。

**模板**：

1. **选源问题** $P'$：已知 NP-complete，且结构与你的问题最接近（这是成败关键）。
2. **构造映射** $f$：把 $P'$ 的任意实例 $I$ 多项式时间映射为你的问题实例 $f(I)$。要写清每个参数怎么设（容量设成什么、权重设成什么）。
3. **证 (⇒)**：$I$ 有解 $\Rightarrow f(I)$ 有解。给出「解如何转换」的构造。
4. **证 (⇐)**：$f(I)$ 有解 $\Rightarrow I$ 有解。给出「反向转换」并验证它确实是 $P'$ 的合法解。
5. **证多项式**：$f$ 的规模与计算时间都是 $|I|$ 的多项式。
6. 结论：若你的问题有多项式算法，则 $P'$ 也有，与 $P'$ NP-complete 矛盾。

**范例结构**（无人机路径类问题的常见套路）

> 从 Hamiltonian Path 归约：令无人机容量为 0（或续航为 0），则所有客户必须由卡车服务，问题退化为「卡车访问全部客户的最短闭合路径」，即 TSP；判定版本即 Hamiltonian 回路。
> (⇒) HP 的解直接作为卡车路径，无人机不使用，全部约束满足。
> (⇐) 任一原问题可行解中，卡车路径必须覆盖全部客户（否则有客户未被服务），去掉无人机架次后即为 HP。
> 映射只改一个参数，显然多项式。故原问题是 NP-hard。∎

**常见错误**：

| 错误 | 说明 |
|---|---|
| 只证一个方向 | 必须双向，否则只是「有解映射」不是等价 |
| 用了指数时间的映射 | 归约必须多项式 |
| 映射改变了问题规模（如把 $n$ 变成 $2^n$） | 同上 |
| 归约到「某个特例」但没说明特例仍在问题族内 | 要显式验证参数取值合法 |
| 引用文献但没核对原文的归约条件 | 标注「未核对」，不进结论 |

## 5. 近似比推导（三步法）

**用于**：算法有理论保证时的核心论证。

**模板**：

1. **构造下界**：对任意实例 $I$，给出 $\mathrm{LB}(I)\le \mathrm{OPT}(I)$，且 $\mathrm{LB}$ 可计算。
2. **界住算法**：证 $\mathrm{ALG}(I)\le \rho\cdot \mathrm{LB}(I)$。
3. **合并**：$\mathrm{ALG}(I)\le\rho\cdot\mathrm{LB}(I)\le\rho\cdot\mathrm{OPT}(I)$，对**所有** $I$ 成立。
4. **紧例**：构造一族实例使比值趋于 $\rho$，说明该界不可改进（不给紧例，审稿人会怀疑界松）。

**范例**（TSP 的 MST 双遍历，2-近似）

> 下界：任一巡游去掉一条边即生成树，故 $\mathrm{MST}\le\mathrm{OPT}$。
> 算法：对 MST 做 DFS，每条树边往返一次，得巡游长度 $2\cdot\mathrm{MST}$。
> 合并：$\mathrm{ALG}=2\,\mathrm{MST}\le2\,\mathrm{OPT}$。
> 紧例：$n$ 个点排在一条直线上、相邻间距 1，星形 MST 的双遍历长度约为 $2(n-1)$，而最优巡游约为 $n$，比值趋于 2。

**常见错误**：

- 用「算法自己的解」当下界（循环论证）。
- 只证了一个实例或平均情况，却写「对所有实例」。
- 界里出现了问题相关的量（如「$\rho$ 取决于数据分布」）——那就不是常数近似比。
- 忘记说明算法**必须返回可行解**（近似比的前提）。
- 量词顺序错：正确是「$\forall I$，$\mathrm{ALG}(I)\le\rho\,\mathrm{OPT}(I)$」，不是「$\exists I$」。

## 6. locality gap

**用于**：局部搜索没有全局保证时，量化「局部最优能差多少」。

**定义**：

$$
\mathrm{LG}=\max_{I}\ \frac{\max_{x\in\mathcal{L}(I)} f(x)}{\min_{x\in\mathcal{F}(I)} f(x)}
$$

其中 $\mathcal{L}(I)$ 是实例 $I$ 的局部最优解集合。

**证上界**（对任意局部最优）：

1. 设 $x$ 是局部最优，$x^*$ 是全局最优。
2. 用「$x$ 不能通过任何单步移动改进」写出一族不等式。
3. 把这些不等式加权求和，构造出 $f(x)\le\rho\,f(x^*)$ 的推导。
4. 权重怎么找：按元素出现频率或按最优点与非最优点的对应关系。

**证下界**（界不可改进）：构造一族实例，使任意局部最优解与全局最优的比值趋近 $\rho$。

**常见错误**：

- 把「实验中的平均比值」写成 locality gap（那是经验值，不是界）。
- 只证上界不构造下界，于是不知道界松不松。
- 邻域定义没写清（1-opt 还是 2-opt 的 locality gap 完全不同）。
- 忽略「局部最优可能不唯一」，只分析了一个特定的局部最优。

**措辞**：可以写「在邻域 $N$ 下 locality gap 至多 $\rho$」；**不能**写「算法误差不超过 $\rho$」——前者是界，后者要看你实际停在哪个局部最优。

## 7. 复杂度紧界与摊还分析

**用于**：算法每步成本、总复杂度的论证。

### 7.1 紧界

- **上界**：数清「每次操作最多做多少次」，逐层相乘。写清是关于哪个参数的函数。
- **下界**：构造实例族，使算法恰好达到上界（不是「最坏情况可能」，而是「存在实例确实如此」）。
- 只给上界时写「$O(\cdot)$」，不要写「复杂度为 $\Theta(\cdot)$」。

### 7.2 摊还分析

| 方法 | 做法 | 适合 |
|---|---|---|
| 聚合法 | 算 $m$ 次操作的总成本，除以 $m$ | 操作序列规律明显 |
| 记账法 | 每次操作多收「信用」，供后续昂贵操作花 | 有明确的「便宜操作攒钱」结构 |
| 势能法 | 定义势函数 $\Phi$，摊还成本 = 实际成本 + $\Delta\Phi$，证其有界 | 数据结构类（扩容、并查集） |

**范例**（动态数组扩容的摊还 $O(1)$，势能法）

> 取 $\Phi=2\,\text{size}-\text{capacity}$（size 为元素数，capacity 为当前容量，容量翻倍增长）。
> 不扩容时：实际成本 1，$\Delta\Phi=2$，摊还成本 $=3=O(1)$。
> 扩容时（size 从 $k$ 到 $k+1$，容量 $k\to2k$）：实际成本 $k+1$，$\Phi$ 从 $2k-k=k$ 变为 $2(k+1)-2k=2$，$\Delta\Phi=2-k$，摊还成本 $=(k+1)+(2-k)=3=O(1)$。
> 故 $m$ 次插入总成本 $O(m)$，摊还每次 $O(1)$。∎

**常见错误**：把「平均情况」当摊还（摊还是对**任意**操作序列的最坏总成本）；势函数取成负数或依赖未来操作；忽略常数因子导致界不紧却被声称紧。

## 8. 证明自检清单

写完一段证明，逐条过：

- [ ] **量词**：写清是「对所有实例存在解」还是「存在实例对所有解」；$\forall/\exists$ 的顺序没有偷换。
- [ ] **边界**：$n=0,1$、空集、单元素、相等元素、退化参数都过了一遍。
- [ ] **可行性**：每个变换（交换、替换、归约映射）都验证了约束仍满足。
- [ ] **引理被用**：每个引理在正文里真的被引用；没被用的删掉（通常是抄来的）。
- [ ] **等号条件**：紧例或等号成立条件给出；没给就说明界可能不紧。
- [ ] **隐含假设**：是否偷偷假设了整数性、一般位置（无并列）、连通性、三角不等式。
- [ ] **归约双向**：两个方向都证了，且映射多项式。
- [ ] **复杂度口径**：上界/下界/紧界说清楚；摊还说清是对什么序列。
- [ ] **与实测分开**：理论结论与实验观察分栏写，不互相支撑。

## 9. 措辞边界：什么情况能说「证明」

| 想写的话 | 必须已有 | 不够的替代写法 |
|---|---|---|
| 「算法保证最优」 | 完整正确性证明（§1 或 §2） | 「在 N 个算例上均达到最优」 |
| 「$\rho$-近似算法」 | §5 三步 + 紧例 | 「实验中平均 gap 为 x%」 |
| 「该问题是 NP-hard」 | §4 完整双向归约 | 「该问题包含 TSP 作为特例」 |
| 「该解最优」 | 证书：LB = 目标值 + `Status=OPTIMAL` | 「求解器返回最优」（要有下界） |
| 「locality gap 至多 $\rho$」 | §6 上界证明 | 「实验中局部最优与最优比值为 x」 |
| 「复杂度 $O(f(n))$」 | 上界推导 | 「实测在 n=1000 时耗时 x 秒」 |
| 「理论上界紧」 | 下界实例族 | 「在我们的算例上界很紧」 |

**一条硬规则**：`运筹内核.md` §6 的措辞纪律在这里同样适用——**没有对应证明，就不能用带保证的词**。写「经验上接近最优」永远安全，写「保证最优」必须能指到某一节的某一步。
