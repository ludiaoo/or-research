# 松弛与下界 · 让「最优」可被证明

> 没有下界，你只有「目前最好」；有了下界，你才有「距离最优还有多远」。
> 所有下界最终都要通过同一个检验：$LB \le z_{IP} \le UB$，且三个数在同一目标口径下。

---

## 1. 三类下界与适用场合

| 类型 | 怎么来 | 强度 | 代价 | 什么时候用 |
|---|---|---|---|---|
| 平凡/组合界 | 放松某条约束后逐元素取最小 | 最弱 | 几乎为零 | 开局估 gap、检查模型有没有写错 |
| LP 松弛 | 去掉整数性，解线性规划 | 中～强 | 小（多项式） | 几乎所有 MILP 的默认下界 |
| Lagrangian | 把难约束乘子化，子问题可解 | 可强于 LP | 中（需迭代） | 约束有结构、子问题有专用算法 |
| 列生成 / DW | 用模式（列）重写，解主问题 | 通常最强 | 大（需定价） | 集合划分型、CVRP、切割下料 |
| 1-tree / Held–Karp | TSP 特有 | 强 | 中 | TSP 及其变体 |

## 2. LP 松弛：先算，再谈强度

实现要点：**同一套 $(c, A, lb, ub)$，只切换 `integrality`**，保证 LP 与 MILP 是同一个模型。

```python
# milp_lab.py 内部就是这么做的
ip = milp(c=c, constraints=A, integrality=np.ones(nv), bounds=bnd)
lp = milp(c=c, constraints=A, integrality=np.zeros(nv), bounds=bnd)
assert lp.fun <= ip.fun + 1e-6          # 下界合法性
gap = (ip.fun - lp.fun) / abs(ip.fun)    # integrality gap
```

判读：

- `gap = 0` 可能是 **结构性的**（全幺模、网络流），也可能是**本算例碰巧**。两者措辞不同：
  - 结构性：可以写「该 formulation 的 LP 松弛在多面体意义上等价于整数 hull」——需要有证明或引用。
  - 碰巧：只能写「在本次 N 组算例上 LP 松弛给出整数解」。
- `gap` 很大 → 优先换 formulation（强形式），而不是换求解器。
- 弱形式的 LP 界若等于「完全放松某约束」的组合界，说明该约束在 LP 里没起作用（p-median 聚合约束是标准例子）。

## 3. 组合下界：最快的那一把尺

| 问题 | 组合下界 | 说明 |
|---|---|---|
| p-median | $\sum_j w_j \min_i d_{ij}$ | 「所有设施都开」的成本，必然 $\le$ 最优 |
| 装箱 | $\lceil \sum q_i / Q\rceil$ | 容量下界 |
| CVRP | $\max\{\lceil \sum q_i/Q\rceil,\ \text{1-tree 界}\}$ | 两个界取大 |
| 指派型 | 放松成指派问题（匈牙利算法） | 多项式可解 |
| 调度 | $\sum p_j$（单机）、$\max\{\sum p_j/m,\ \max p_j\}$（并行机） | 工作量界 |

组合界便宜、稳定，适合做**sanity check**：任何「最优解」都不能低于它。若低于，先查可行性。

> **组合界常常松一根，别拿它当最优性依据**。实测例子（一维下料，Q235 批 58 件）：
> 体积界 $\lceil 94274/6000\rceil=16$，LP 界 16.4737，整数最优 17。
> 只有 LP 界上取整才把 17 钉死；体积界只能证明「≥16」，差一根。
> 用法：组合界做快速 sanity check 与算法 early-exit；**声称最优时必须给 LP/对偶界**。
> 另注意下界的方向纪律：算偏小仍合法，算偏大就非法——所以锯缝、损耗这类小项宁计勿漏。

### 3.1 「指派 + 机器容量」型：子集界往往就等于 LP 界

结构：每件活派给一台机器（$x_{ij}\in\{0,1\}$，$\sum_j x_{ij}=1$），
机器完成时刻 $L_j=\sum_i p_i x_{ij}\le c_j z$。这类模型的**子集界**是

$$z\ \ge\ \max_{S\subseteq M}\ \frac{\sum_{i:\,E_i\subseteq S} p_i}{\sum_{j\in S} c_j}$$

含义：只能落在 $S$ 里的活，一定由 $S$ 消化。$|M|=3$ 时只有 7 个子集，$O(2^{|M|}n)$ 秒出。

实测（22 周平行机排产）：**子集界与 LP 最优值逐周相等**（最大差 1.8e-15）。
所以这个结构上不必单独跑 LP——先算子集界，若它已等于整数解，根节点就是证书；
若不等，再跑 LP（此时 LP 一定不会更好，只会说明整数性缺口）。
反过来也要小心：**换成带 setup / 时间索引的版本，这个等式不成立**，别把结论当定理搬走。

## 4. Lagrangian 松弛

原问题 $\min c^\top x$ s.t. $Ax \ge b,\ x\in X$（$X$ 为「好解」的集合，如网络流、背包、指派）。

$$
L(\lambda)=\min_{x\in X}\ \big[c^\top x+\lambda^\top(b-Ax)\big],\qquad \lambda\ge 0
$$

对任意 $\lambda\ge0$，$L(\lambda)$ 是原问题最优值的下界；最好的界是

$$
\max_{\lambda\ge0} L(\lambda)\ \le\ z_{LP}
$$

（当 $X$ 满足整数性时取等；否则可能严格更强。）

次梯度法：

```
λ ← 0
for k in 1..K:
    x_k ← argmin_{x∈X} [c'x + λ'(b - Ax)]
    g ← b - A x_k                    # 次梯度
    LB ← max(LB, c'x_k + λ'g)
    if ||g|| == 0: break             # 已最优
    θ ← α (UB - LB) / ||g||²          # α 从 2 递减到 0.01
    λ ← max(0, λ - θ g)              # 注意符号：g ≥ 0 表示约束被违反
```

要点：

- **UB 必须来自可行解**；用不可行解算步长会让界失真。
- 记录**每轮的 LB 曲线**，收敛慢是结果，不是失败。
- 子问题若有专用算法（最短路、背包 DP），Lagrangian 才划算；否则不如直接 LP。
- Lagrangian 界与 LP 界的关系要在论文里说清，不能把「Lagrangian 界」写成「LP 界」。

## 5. 列生成与 Dantzig–Wolfe

适用于「可行解 = 若干模式的组合」：CVRP、切割下料、乘务排班、集合划分。

限制主问题（RMP）：

$$
\min \sum_{p\in P'} c_p \lambda_p \quad\text{s.t.}\quad \sum_{p} a_{ip}\lambda_p \ge d_i,\ \ \lambda_p\ge0
$$

- 定价：找 $\min_p (c_p - \pi^\top a_p) < 0$ 的列；找到就加，找不到则 RMP 最优 = 全主问题 LP 最优。
- **RMP 的最优值是合法下界**（对最小化），可随时报告收敛曲线。
- 只解 LP 得到的是下界；要整数解需 branch-and-price，或对最终列做整数规划（可能不最优）。

## 6. CP-SAT 的界

约束规划求解器也维护目标下界（如 OR-Tools 的 `BestObjectiveBound`）。它的界**不与 LP 界可比**，报告时要写清来源，不能混在同一列。

## 7. 必须成立的不变量（直接写成断言）

```python
assert lb <= z_ip + 1e-6 * max(1, abs(z_ip))     # 下界合法
assert z_ip <= ub + 1e-6 * max(1, abs(ub))       # 可行解不优于上界
assert abs(z_enum - z_ip) <= 1e-6 * max(1, abs(z_ip))   # 独立精确解一致
assert status == OPTIMAL and mip_gap <= 1e-9      # 才允许写「最优」
```

- 不同 formulation 的**整数最优值必须相同**（差在容差内）；不同就说明模型不等价。
- LP 界随 formulation 变强而**单调不减**（最小化）；变小了一定是写错了。

## 8. 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 拿启发式最好解当下界 | 「gap」变成 0，结论虚高 | 下界必须来自松弛/对偶，且可复算 |
| 用不同目标口径算 LB 与 UB | 界不可比，gap 无意义 | 统一量纲、统一常数项 |
| 只报 LP 界不报求解器对偶界 | 读者无法验证 | 两个都报，注明来源 |
| 把 `status=LIMIT` 的解写「最优」 | 结论错 | 写「时限内最好可行解 + 当前 gap」 |
| 忽略数值容差 | 1e-9 的违约被当成可行 | 统一容差并在文中声明 |
| LP 与 MILP 用了不同约束集 | gap 无意义 | 同一矩阵，只切 integrality |
