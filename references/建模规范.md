# 建模规范 · 模型卡与线性化

> 目标不是写出漂亮公式，而是写出**能被检验、能被复现、边界清楚**的模型。
> 经验：绝大多数「算法效果不对」最后都追到模型或评估器，而不是搜索策略。

---

## 1. 模型卡八段（与 `02_模型卡.md` 一致）

1. **集合与索引**：$I,J,K,T$，写清基数与下标范围；动态集合说明怎么生成。
2. **参数**：符号、含义、单位、取值、标注 `[给定] / [假设] / [扩展]`。
3. **决策变量**：符号、类型、维度、取值范围、业务含义。
4. **目标函数**：完整表达式 + 逐项解释 + **量纲检查** + 各项量级占比（用基准算例估）。
5. **约束**：逐条编号，表达式 / 业务解释 / 硬软 / 违约码 / 规模。
6. **formulation 对照**：至少两套，变量数、约束数、LP 松弛值。
7. **线性化与合法化**：Big-M 来源、对称性处理。
8. **理论性质**：复杂度、可行域结构、有效不等式、与松弛的关系。

编号在全文一致：代码注释、违约码、文档、实验表都引用同一编号。

---

## 2. 符号与命名

- 集合大写斜体 $I$，参数小写，变量小写带下标；0-1 变量用 $x,y,z$，连续用 $f,t,u$。
- 下标顺序固定（如 $x_{ij}$ 恒为「从 $i$ 到 $j$」），不要在不同约束里换顺序。
- 避免一符多义：$d$ 不要同时表示距离和需求；$p$ 不要同时表示设施数和加工时间。
- 代码里的变量名与论文符号一一对应（`x_ij` ↔ $x_{ij}$），方便核对。

| 参数 | 值 | 单位 | 标注 | 依据 |
|---|---|---|---|---|
|  |  |  |  |  |

## 4. 线性化模式

| 非线性 | 线性化 | 注意 |
|---|---|---|
| 0-1 × 连续：$z=xy$ | $z\le Mx$，$z\le y$，$z\ge y-M(1-x)$ | $M$ 取 $y$ 的上界，越小越好 |
| 两个 0-1 相乘 | $z\le x$，$z\le y$，$z\ge x+y-1$ | 无需 M |
| $\max(x_1,\dots)$ | $z\ge x_i$，目标最小化时自动成立 | 目标方向必须一致 |
| $\min(x_1,\dots)$ | $z\le x_i$ + 指示变量，或用大 M | 单独用会漏 |
| $|x|$ | $z\ge x$，$z\ge -x$（最小化时） | 最大化时需拆正负部 |
| 固定费用 | $f\le M y$ | $M$ = 该设施最大可能流量 |
| 时间窗/次序 | $t_j\ge t_i+s_i+\tau_{ij}-M(1-x_{ij})$ | $M=b_i+s_i+\tau_{ij}-a_j$ |
| 分段线性 | SOS2 / 增量法 | 段数影响规模 |
| 指示约束 | 大 M 或 indicator（若求解器支持） | indicator 通常更强 |

**Big-M 纪律**：取最小合法值、说明来源、做一次 M 的敏感性。用 $10^9$ 会让 LP 松弛烂掉，还容易数值溢出。

## 5. 规模估算

写代码前先估：

$$
\text{变量数}\approx |I|\cdot|J|\cdot|K|,\qquad
\text{约束数}\approx \text{每个约束的条数之和}
$$

- 超过 $10^6$ 变量：先想能不能换写法（弧流 vs 时间索引、聚合 vs 逐条）。
- 约束数指数级（SEC）：不要全部枚举，用分离或按需添加。
- 对称性（相同车辆/机器/箱子）：加破缺约束，否则分支树爆炸。

---

## 6. 正确性检验（四层）

1. **特例检验**：把参数设成退化值，模型应退化成已知可解问题。例如 $p=1$ 的 p-median 就是「选一个点使加权距离最小」，可直接穷举核对。
2. **小规模穷举**：$n\le10$ 时枚举全部组合，与 MILP 逐位对照。
3. **松弛检验**：$LB\le z_{IP}$；不同 formulation 的整数解相同。
4. **解校验**：独立校验器（不调用求解器）复核约束与目标；故意构造违约解，确认会被拒。

四层都过，才敢说「模型对」。

---

## 7. 常见建模错误

| 错误 | 后果 |
|---|---|
| 漏掉「每个客户恰好服务一次」 | 解会少服务客户，目标虚低 |
| 用 $\le$ 代替 $=$ 的分配约束 | 可行域变大，解不可行 |
| 容量约束写成「总量 ≤ 容量」而没按车/按路径 | 单车超载被允许 |
| 时间递推漏掉服务时间 | 时间窗约束形同虚设 |
| 目标里漏常数项 | 与文献数值不可比 |
| 连续变量当 0-1 用 | 出现分数解 |
| 同一资源被两个任务同时占用未建模 | 求解器专找这种漏洞 |
| 软约束惩罚系数过大/过小 | 要么等于硬约束，要么形同虚设 |
