# 写作与审稿 · 把结果写成能被接受的论证

> 运筹优化论文的说服链是：**问题重要 → 模型正确 → 性质清楚 → 算法有理 → 实验可信 → 结论不越界**。
> 任何一环缺失，审稿人就会用一句话否掉整篇。

---

## 1. 结构（期刊/会议通用）

| 节 | 必须回答 | 常见缺陷 |
|---|---|---|
| Abstract | 问题、方法、**具体量化结果** | 只写「效果显著」，不给数字 |
| Introduction | 为什么难、为什么重要、贡献 3 条 | 贡献写成「我们做了实验」 |
| Literature | 三到五条脉络，不是文献罗列 | 只引不评，没说自己差在哪 |
| Problem definition | 符号、假设、输入输出 | 假设藏在正文里，模型节才出现 |
| Model | 完整 formulation + 逐条解释 | 缺约束解释、缺量纲 |
| Theoretical properties | 复杂度、下界、性质、证明 | 只有「显然」没有证明 |
| Algorithm | 伪代码 + 组件 + 复杂度 | 参数没来源，终止判据不清 |
| Computational study | 算例、基线、指标、统计 | 基线弱、时限不公、只报平均 |
| Conclusion | 结论、局限、未来工作 | 把没测的写成已证 |

---

## 2. 模型节怎么写

1. **先给假设，再给符号**。每条假设编号（A1, A2…），后面实验要能对应。
2. 集合/参数/变量分三张表，参数带单位与来源（`[给定] / [假设] / [扩展]`）。
3. 目标函数写成一行公式 + 逐项解释 + 量纲检查。
4. 约束逐条编号，每条后面跟一句业务解释；硬/软分开。
5. 若有多套 formulation，**明确说哪套用于实验、为什么**；强弱对比放附录或实验节。
6. 非线性项给出线性化过程，Big-M 说明取值来源。

反例（常见但没用）：

> 「我们建立了如下模型：min f(x) s.t. 约束 (1)-(8)。」

读者无法判断约束是否漏、是否冗余、是否等价。

---

## 3. 命题与证明

- 命题要有**明确前提**：「在假设 A1–A3 下，算法 1 的输出是可行解」。
- 证明分三段：构造 → 可行性 → 最优性/界。
- 复杂度结论写清是**最坏情况**还是**期望**，以及关于哪个参数。
- 引用文献结论时写清适用条件（度量？权重？容量？$p$ 是否固定？），不要张冠李戴。

---

## 4. 实验节怎么写

固定顺序：**算例 → 基线 → 指标 → 主表 → 消融 → 敏感性 → 失败案例**。

- 第一段就说清「和谁比、在什么算例上、什么时限」。
- 主表每行可追到 CSV；表注写时限、硬件、参考值类型。
- 消融要回答「哪个组件贡献了多少」，不是「去掉之后变差了」。
- 敏感性要给趋势，不是只报最好那组参数。
- **负结果照写**：某类算例上不如基线，是发现，不是污点。

## 5. 措辞纪律

| 想写 | 必须先有 |
|---|---|
| 「最优解」 | `status=OPTIMAL` + `MIPGap=0` + 合法下界；小规模另有独立精确解对照 |
| 「提升 x%」 | 分母明确（BKS / LB / 哪条基线）、同算例同口径、样本规模 |
| 「LP 松弛是紧的」 | 只写「在本次 N 组算例上 gap=0」；不宣称 formulation 理论上 ideal |
| 「算法有效 / 有保证」 | 近似比或 locality gap 的**确切适用条件**；算例上达到最优 ≠ 保证 |
| 「优于现有方法」 | 同算例、同时限、同调参预算的对比；否则写「在本文实验设定下」 |
| 「平均成本 / 总距离」 | 声明量纲、坐标系、距离度量；不可跨文献比较 |

## 6. 审稿人必问的 12 个问题

| 问题 | 准备什么 |
|---|---|
| 1. 为什么不直接用求解器？ | 规模-时间曲线，或求解器在 L 档超时 |
| 2. 基线是不是太弱？ | 强基线（SOTA 复现或求解器）+ 同时限 |
| 3. 调参公平吗？ | 调参集/预算/搜索空间，各臂相同 |
| 4. 有没有下界？ | LP / Lagrangian / 组合界，并报 gap |
| 5. 算例是不是挑过？ | 事前定算例集，全报，含失败 |
| 6. 结论能推广吗？ | 规模/分布敏感性，明确适用边界 |
| 7. 复杂度分析呢？ | 单步与总复杂度，关于哪个参数 |
| 8. 和文献数字能比吗？ | 只比 gap，说明参考值类型与年份 |
| 9. 随机性怎么控制？ | 种子、重复次数、分布图 |
| 10. 为什么这个邻域有效？ | 消融 + 邻域连通性讨论 |
| 11. 模型假设合理吗？ | 逐条假设的现实依据与放松方向 |
| 12. 可复现吗？ | 代码/数据/命令/环境，干净环境可跑 |

---

## 7. 复现包

```
code/       运行脚本 + 依赖清单（版本）
data/       算例（或生成器 + 种子）
results/    原始输出（只读）
README      环境、命令顺序、预期产物、运行时长
```

- 一条命令能跑通「小算例 → 主表」。
- 预期输出写进 README，别人才能判断是否跑对。
- 缺许可证时给降级路径（HiGHS / 枚举），并说明差异。

---

## 8. 常见拒稿原因（按频率）

1. 没有下界或最优性证据，「最优」站不住。
2. 基线弱、时限不公、调参不对等。
3. 算例单一或挑过，结论不可外推。
4. 模型与文献重复，贡献不清。
5. 实验只报平均，没有分布与显著性。
6. 假设不合理且未讨论。
7. 不可复现（缺数据/参数/代码）。
