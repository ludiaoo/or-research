# 无人机配送专题 · 建模要素与常见坑

> 只做领域定位用。**具体公式、参数、算例以原文为准**；这里给的是建模时必须显式处理的要素、文献坐标和容易翻车的地方。

---

## 1. 问题族坐标

| 问题 | 代表文献 | 卡车 | 无人机 | 关键约束 |
|---|---|---|---|---|
| TSP-D | Agatz, Bouman & Schmidt (2018) | 单车主路径 | 单机、单次起降 | 无人机服务一个客户后在另一点归队 |
| FSTSP | Murray & Chu (2015) | 主路径 | 单机、多 sortie | 发射/回收节点、续航、卡车可继续行驶 |
| mFSTSP | Murray & Raj (2020) | 主路径 | **多机** | 每机独立载荷/续航、同步与等待 |
| 卡车-无人机协同配送（含换电/悬停） | 项目自有设定 | 视设定 | 视设定 | 见 §4 |

先判断你的问题落在哪一格，再决定抄哪套骨架。**mFSTSP 不是 FSTSP 加一个下标**：多机引入机队调度、载荷分配和同步，模型结构会变。

## 2. 必须显式建模的四件事

### 2.1 时间同步

- 无人机在节点 $i$ 发射，服务客户 $k$，在节点 $j$ 回收；卡车到达 $j$ 的时刻必须与无人机到达时刻匹配。
- 两种处理：卡车等待（等待计入完工时间）或无人机等待（需满足续航）。**不能假设零等待**。
- 常见错误：只写「无人机飞行时间 ≤ 续航」，不写卡车与无人机的时间关系 → 目标被系统性低估。

### 2.2 能量 / 续航

- 用能量模型而非「距离 ≤ 最大航程」；载荷影响能耗（Dorling 等 2017 的线性模型是常见起点）。
- 电池更换、充电时间是否计入，取决于设定；换电与充电是两种不同模型。
- 常见错误：用欧氏距离除以速度当时间，忽略起降、悬停、爬升。

### 2.3 载荷

- 多机时每架独立载重；不能把机队载重合并成一个容量。
- 载重与能耗耦合：载重越大续航越短，约束是非线性的，需要线性化或分段。

### 2.4 起降点

- 是否允许在任意客户点起降，决定变量维度（$O(n^2)$ 的 sortie 变量 vs 仅在卡车停靠点）。
- 允许任意点起降会让模型规模爆炸，通常需要列生成或限制候选集。

## 3. 建模骨架（结构，不是完整公式）

常用三层变量：

1. **卡车路径**：$x_{ij}\in\{0,1}$，度约束 + 子回路消除。
2. **无人机 sortie**：$s_{ikj}\in\{0,1\}$ 表示「在 $i$ 发射、服务 $k$、在 $j$ 回收」。
3. **时间变量**：卡车到达 $t_i$、无人机发射/回收时刻，配大 M 或时间索引。

目标通常是最小化完工时间（makespan）或总成本（卡车行驶 + 无人机能耗）。

LP 松弛通常很弱（大 M + 同步约束），所以：

- 小规模用 MILP 求最优，报 gap；
- 中大规模用 ALNS / 自适应大邻域，邻域里显式维护「sortie 插入/移除」；
- 下界可用「忽略同步的松弛」或「仅卡车 TSP 界」，并说明放松了什么。

## 5. 常见坑（领域特有）

| 坑 | 后果 | 处理 |
|---|---|---|
| 忽略卡车等待 | 完工时间偏乐观 | 显式时间变量 + 同步约束 |
| 用距离代替能量 | 续航约束失真 | 能量模型 + 载荷耦合 |
| 多机共用载荷变量 | 可行域被放大 | 每机独立变量 |
| 允许任意点起降 | 规模爆炸 / 不可解 | 限制候选点或列生成 |
| 只测单机、声称适用多机 | 结论越界 | 分开测，或明确写「单机设定」 |
| 算例参数不写 | 无法复现 | 速度、续航、载荷、坐标分布全列 |
| 与 TSP-D 直接比目标值 | 口径不同 | 只比 gap，说明参考值与设定差异 |

## 6. 读论文时的检查清单

- [ ] 卡车是否必须回到仓库？无人机是否必须回到卡车？
- [ ] 一个 sortie 服务几个客户？（多数设定是 1 个）
- [ ] 卡车在无人机飞行期间能否继续服务其他客户？
- [ ] 电池：换电 / 充电 / 不换，时间算不算？
- [ ] 目标：makespan / 总成本 / 能耗 / 加权？
- [ ] 算例规模与生成规则？
- [ ] 是否给了下界或最优性证明？

这七个问题答不上来，就没法判断能不能复现、能不能比较。
